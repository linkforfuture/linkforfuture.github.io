# 工作文档

这里整理了我之前做过的需求设计文档，主要是 HCCL（集合通信库）相关的 SRS/SD 需求文档、设计方案、改造与实现计划、问题定位与分析报告等。

## 目录结构

| 分类 | 说明 |
| ---- | ---- |
| **需求文档（SRS/SD）** | 需求规格说明与方案设计文档 |
| **设计 / 方案** | 系统设计、改造方案、实现计划 |
| **拓扑（Topo）** | 拓扑匹配、解析、物理层级相关设计 |
| **分析报告** | 问题定位、崩溃分析、优化分析、测试计划 |
| **HCOMM 分析** | 通道连接与数据流分析 |

## 如何使用

- 左侧侧边栏按主题分组导航，点击即可阅读；
- 右上角可**全文搜索**（输入关键词即可）；
- 代码块支持语法高亮，图片点击可放大。
