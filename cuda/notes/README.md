## 如何新增记录

```bash
cp -n cuda/notes/template.md cuda/notes/2026-09-27-vector-add.md
```

上面的日期是示例，使用实际日期和主题命名；若文件已存在，继续编辑原记录或选择新名称。填好后，在本页下方添加指向记录的 Markdown 链接，并把文件加入 `cuda/_sidebar.md` 的“学习记录”分组，这样可以从侧边栏阅读。
